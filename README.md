# B4 YEOJUNG 홈페이지 수정본

index.html을 브라우저에서 열면 실행됩니다. 설치가 필요하지 않습니다.

메인은 히어로 → 4개 지역 카드 → 여행 안내 → 다음 여행 계획 → 푸터로 구성됩니다.
서울·부산·강릉·제주 메뉴 클릭 시 해당 지역 상세 화면만 표시됩니다.
여행코스는 PNG 일러스트와 연결선으로 이동 순서를 표시합니다.
명소·맛집·카페 실사 PNG 89장과 위치·영업시간·전화·지도 링크를 포함합니다.
행사 8개는 실제 사진과 공식 홈페이지 링크, 확인된 조건을 제공합니다.
미니게임 12개에서 클리어 티켓을 받고 내쿠폰함에 브라우저 로컬 저장합니다.

## 자료

조사일: 2026-10-13. data-catalog.json에 항목별 정보·사진 출처·운영정보 참고사항이 있습니다.
범위: 요청하신 4개 지역의 89개 장소(전국 전체 장소를 수집한 데이터베이스는 아닙니다).
실사진은 공개된 해당 장소 자료를 다운로드해 PNG로 변환했습니다. 사진마다 원본 해상도가 다르며 확대하지 않았습니다.
확인 불가한 방문 정보 필드 0개는 공식 안내 확인 필요로 표시합니다. 일반 야외 명소의 안내 전화는 관광 안내센터일 수 있습니다.
원본 사이트별 사진 사용 조건을 data-catalog.json의 출처에서 확인할 수 있습니다.
게임 쿠폰은 제휴 전 체험용이며 실제 매장에서 사용할 수 없습니다. 내쿠폰함은 같은 브라우저에만 저장되며 브라우저 데이터 삭제 시 초기화됩니다.

## 검증

89개 장소와 이미지 일치 키, PNG 파일 형식 및 중복 해시 검사.
지역별 전환, 코스, 맛집/카페, 게임 12개 실행, 성공 티켓과 쿠폰 저장 유지, 마우스 오버 드롭다운, 모바일 가로 넘침 검사.
